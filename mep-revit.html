MEP Building Modeling & Revit As-Built Documentation

Engineering Internship Project

Developed and updated a building model using Autodesk Revit during my engineering internship. This project provided hands-on experience with Building Information Modeling (BIM), MEP systems, and professional engineering documentation workflows.

Project Overview

During my internship, I worked on updating an existing building model in Autodesk Revit. Using engineering documentation and existing drawings, I helped improve the accuracy of the digital representation of the building and supported coordination of building systems.

My Contributions

  • Updated and modified building elements within an existing Revit model
  • Worked from AutoCAD files and engineering documentation
  • Modeled and adjusted MEP-related components
  • Created and modified views to support documentation
  • Improved understanding of BIM workflows used in industry

Software & Tools

  • Autodesk Revit
  • AutoCAD
  • Building Information Modeling (BIM)

Engineering Skills Developed

  • 3D building modeling
  • MEP coordination
  • Engineering drawing interpretation
  • Digital documentation workflows
  • Professional CAD/BIM practices

Project Reflection

This project strengthened my understanding of how engineering teams use digital models to communicate design information and coordinate building systems. Working in Revit allowed me to apply my CAD experience in a professional environment while learning industry standards for building documentation.
